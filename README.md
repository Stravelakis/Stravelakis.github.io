# Stravelakis.github.io

The organisation site for Stravelakis, served at **https://docs.stravelakis.com**.

Why this repository exists: GitHub Pages serves every project site that has no
custom domain of its own under the organisation site's domain. So because this
site owns `docs.stravelakis.com`, each project's documentation appears at
`docs.stravelakis.com/<repository>/` automatically — for example
[docs.stravelakis.com/image-forge/](https://docs.stravelakis.com/image-forge/).

To add a project: publish its docs with GitHub Pages, **do not** give that
repository its own custom domain, and add a link to it in `index.html` here.
