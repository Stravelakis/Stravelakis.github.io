What it does

Free AI changes without warning. Models get added, quietly rate-limited, moved behind a paywall, or retired. The first you hear about it is your app breaking at 2am.

The Nein watches eleven providers every day, checks what is really free and really working, and publishes the result twice: as a page people can read, and as JSON that an agent can read.

It tracks only things a program can call: models your own code reaches over an API, endpoints an agent can use unattended, free tiers and permanently zero-priced endpoints. Chat websites, desktop apps, paid tiers, and models you download and run yourself are out of scope.

What makes it different

Tested, not claimed

Tool calling, JSON mode, streaming and system-prompt handling are checked with real requests. Many free endpoints list a model and then quietly ignore your tool definitions.

Unknown is never "false"

Untested is not unsupported. The page shows three states, not two.

The fine print is a column

Credit card or phone required, region limits, whether they train on your data, whether commercial use is allowed.

A rate limit counts as success

A 429 proves the model and the account exist. A server error counts as nothing: no new knowledge.

Every number has a source

Where it came from, when it was seen, and whether two sources disagreed. Disagreements are published, not hidden.

It says when it does not know

If a provider's terms could not be confirmed, the entry carries a "what we cannot confirm" note instead of a confident guess.

For agents

Every endpoint is open, cacheable and needs no login. Paths on a site that runs it:

/wp-json/nein/v1/status.json         health, freshness, next check
/wp-json/nein/v1/models.json         every model, filterable
/wp-json/nein/v1/providers.json      providers, confidence, conflicts
/wp-json/nein/v1/capabilities.json   tested tool calling, JSON mode, streaming
/wp-json/nein/v1/changes.json        rolling 90-day change feed
/wp-json/nein/v1/sources.json        where every number came from
/wp-json/nein/v1/pick                describe a need, get a ranked fallback chain

pick is the useful one. Describe what you need (for example an image-input model with a large context window that supports tools) and it returns models that are free and confirmed working right now, in fallback order. Try rank 1, fall through on failure or rate limit.

Every response says how old its data is and how fresh it is, so an agent can judge how far to trust it.

How it is built

Two halves. A private collector holds every credential, checks every provider and works out the state. It sends a signed report to a public WordPress plugin. The plugin holds no secrets, shows what it is told, and never calls out.

The collector is not published. The interface between the two is: a payload schema anyone can build a collector against.

Privacy and good manners

Privacy

  • Provider logos are self-hosted, so visiting the page tells no AI company anything.
  • No third-party requests, no trackers, no externally loaded fonts.
  • Analytics are front-end only: what was clicked and filtered. No IP storage.

Being a good guest

  • One request per 20 to 40 seconds, randomised.
  • At most two immediate retries, only after a failure.
  • A hard daily request budget per provider.
  • A 429 is honoured, never worked around.
  • If a provider says something is wrong, it is corrected within 24 hours.

Who it is for

  • Developers and agent builders who need a free model that really works, and a fallback when it stops.
  • WordPress site owners who want to publish an honest, always-fresh page on free AI.
